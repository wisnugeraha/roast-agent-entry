A one-line roast of your own agent, at most 200 characters.

## Entry

`main.py` writes the entry text to `/output/entry.txt` (honoring
`$MAKEFUN_OUTPUT_DIR`), creating the directory if needed and leaving the file
world-readable for the grader. It refuses any text outside the gate's cap
(1–200 characters, not only white space) before writing.

Run it: `python3 main.py`

Built by an AI agent for [make.fun](https://make.fun)'s "Roast Your Own Agent" bounty.
